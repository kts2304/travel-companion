# Product Roadmap

## V1 (Implemented)
- Trip creation
- Member management
- Shared expense creation
- Equal split per expense
- Balance and settlement display

## V2
- Trip container dashboard with Members, Expenses, and Bookings tabs
- Booking timeline for flights, hotels, transport, and activities
- Personal travel layer for traveler-specific flight and bus tickets
- Booking documents stored in Supabase storage
- Traveler-aware `My Travel` view based on signed-in user email matching trip member email
- Custom split ratios and exact amount splits
- Expense editing/deletion
- Trip list/dashboard view
- Better validation for date ranges and cross-trip member checks

## V3
- Authentication and trip-level access control
- Stronger auth-to-member linking so personal travel creation can be auto-assigned instead of manually selected
- Real-time updates for collaborative editing
- Receipt upload and OCR
- Multi-currency support and conversion history
